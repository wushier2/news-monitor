# Public Opinion Monitor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and privately deploy a Sites-hosted public-opinion monitor that collects four specified public news channels, stores seven days of deduplicated history, and refreshes every five minutes while the dashboard is open.

**Architecture:** A vinext application serves a feed-first React dashboard and route handlers. Four isolated source adapters normalize public HTML or embedded JSON into one domain model; an ingestion service validates and upserts records into Cloudflare D1. The browser invokes the same refresh endpoint on first load when stale, every five minutes while open, and on explicit user request.

**Tech Stack:** vinext, React, TypeScript, Cloudflare Workers, Cloudflare D1, Drizzle ORM, Cheerio, Vitest, Sites hosting

export async function fetchText(url: string, timeoutMs = 8_000): Promise<string> {
  const response = await fetch(url, {
    headers: { "user-agent": "Mozilla/5.0 PublicOpinionMonitor/1.0" },
    signal: AbortSignal.timeout(timeoutMs),

}
